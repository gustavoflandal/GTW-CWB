# Referência — Menus, Funcionalidades e Grupos de Acesso (dados do banco DEV)

Snapshot de 2026-10-08 de GTW_MURALHA_DEV, atualizado em 2026-10-20 (consultas `SELECT`) com os grupos 102–109, as funcionalidades 366–438, os cards de `sis_menu_infos` e as contagens de direitos — inclui as migrações [`20261018_remove_cards_duplicados.sql`](../banco-de-dados/migracoes/20261018_remove_cards_duplicados.sql), [`20261018_renomeia_card_configuracao_monitoramento.sql`](../banco-de-dados/migracoes/20261018_renomeia_card_configuracao_monitoramento.sql), [`20261019_analise_permissao_abrir_superset.sql`](../banco-de-dados/migracoes/20261019_analise_permissao_abrir_superset.sql) e [`20261019_registro_modulos_novos.sql`](../banco-de-dados/migracoes/20261019_registro_modulos_novos.sql). Modelo: `sis_menu` (funcionalidade/ação protegida) ← `sis_menu_direitos` (direito por grupo ou por usuário) → `sis_grupo` ← `sis_usuario_grupo` → `sis_usuario`. Menus exibidos na barra: `sis_menu_infos` (Processamento), `sis_menu_relatorio_infos` (Relatórios), `sis_menu_graficos_infos` (Gráficos). A verificação de acesso por URL usa `dbo.fcn_VerificaAcesso(acao, id_usuario)`: se a ação não está cadastrada em `sis_menu.acao` (cnt = 0) o acesso é **liberado**; se cadastrada, exige direito via grupo ou usuário.
