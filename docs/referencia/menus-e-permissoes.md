# Referência — Menus, Funcionalidades e Grupos de Acesso (dados do banco DEV)

Snapshot de 2026-10-08 de GTW_MURALHA_DEV. Modelo: `sis_menu` (funcionalidade/ação protegida) ← `sis_menu_direitos` (direito por grupo ou por usuário) → `sis_grupo` ← `sis_usuario_grupo` → `sis_usuario`. Menus exibidos na barra: `sis_menu_infos` (Processamento), `sis_menu_relatorio_infos` (Relatórios), `sis_menu_graficos_infos` (Gráficos). A verificação de acesso por URL usa `dbo.fcn_VerificaAcesso(acao, id_usuario)`: se a ação não está cadastrada em `sis_menu.acao` (cnt = 0) o acesso é **liberado**; se cadastrada, exige direito via grupo ou usuário.
